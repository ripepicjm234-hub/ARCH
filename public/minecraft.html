Minecraft · browser edition

Horizon

Horizon is an experimental Minecraft: Java Edition client that runs in a WebGPU-capable browser. Its packaged game is not installed on Arch yet.

  • You need your own Minecraft: Java Edition copy and locally prepared game resources.
  • The browser build requires WebGPU and cross-origin isolation; Chrome or Edge is recommended.
  • Arch does not bundle Minecraft files or provide a hosted Horizon build yet.
Open Horizon on GitHub Browser build guide

After building and packaging Horizon from your own game resources, copy the package contents into public/horizon/. The Minecraft tile will then launch it here. Keep the package private and out of public source control; it contains Minecraft assets.
